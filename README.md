# Kinetic — Beneath every jump

An interactive, self-contained guide to dance jump anatomy, tissue loading, and recovery.

Website after GitHub Pages is enabled: [Kinetic](https://katherineyzhu-sketch.github.io/Dance_injuries/).

## Movements

- **Sauté:** front view, with continuous jumps and immediate plié landings.
- **Grand jeté:** side view, repeating plié → leap → landing plié.
- **Échappé sauté:** front view, jumping from first to second and closing in first, with plié at each landing.

Play, pause, slow down, or scrub the animations, and select anatomical structures to explore illustrative loading explanations.

## Hosting

This is a static website with all styling, illustrations, and JavaScript in `index.html`. No build or dependencies are required. In GitHub Pages settings, publish the `main` branch from `/ (root)`. The `.nojekyll` file enables direct static hosting. Updates to `index.html` on `main` are published automatically.

You can also download `index.html` and open it in a modern browser. Only the external reading and video reference links require internet access.

## Educational scope

The anatomy, movements, and loading curves are simplified educational illustrations. They are not motion-capture measurements, a validated biomechanical simulation, injury predictions, or clinical advice.
